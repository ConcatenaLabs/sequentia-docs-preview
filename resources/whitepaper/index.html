Whitepaper

The whitepaper is the authoritative description of Sequentia’s protocol. This site simplifies it; where the two differ, the whitepaper is right.

Not a promise. The protocol as it runs today.

Read it

Sequentia Technical Whitepaper, by Alberto De Luigi. Revised edition, October 2026. About twenty pages.

We present a Byzantine Fault Tolerant protocol based on a Proof-of-Stake consensus designed to work in a partially synchronous network, using Bitcoin’s Proof-of-Work to define time boundaries which enable the activation of an exception rule that ensures network liveness in case of a stall due to missing participants.

In plainer words: a proof-of-stake chain that is final in seconds, uses Bitcoin as its clock so that it never gets stuck, uses Bitcoin as its source of randomness and its checkpoint log, and is designed so that trades between it and Bitcoin are as consistent as trades within one chain.

What the revised edition changed

The first edition, in 2022, was a theoretical paper: it proposed mechanisms and left details open. The current edition reflects the protocol as it has been implemented, tested and run in public. Where the original proposed a mechanism, this one states the rule that was adopted, the number that was chosen, and the reason.

Four elements moved from “most likely solution” to settled consensus rule:

  1. The committee is a public, fixed-size set of at most 250 signers that certifies each block with a single aggregated signature.
  2. The leader election is exactly proportional to stake and gives no advantage to splitting it.
  3. The pace of the chain, one block per sixty seconds at the fastest, is a consensus rule and not a convention of the software.
  4. Immediate finality is stated precisely as finality modulo Bitcoin: a certified block is final against every competitor inside Sequentia and is undone only if the Bitcoin block it references is undone.

The market figures were also updated from 2022 to 2026, and a section on rollups was added to the survey of other designs.
