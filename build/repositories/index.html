Repositories

For developers

All of Sequentia is developed in the open at github.com/ConcatenaLabs. This page maps the repositories by layer.

The protocol itself is documented in the node repository, under doc/sequentia/. Each application documents itself in its own README.

How the pieces fit

The chain

Repository What it is
Sequentia The node, Sequentia Core (sequentiad, sequentia-cli, sequentia-qt): a fork of Elements 23.3.3. Consensus, anchoring, proof of stake, the open fee market, the price server, and the protocol documentation.
sequentia-testnet-ops Host configuration of the public testnet’s server.

Libraries

Repository What it is
SWK Sequentia Wallet Kit, a fork of Blockstream’s LWK: a Rust wallet library with a CLI and WebAssembly and multi-language bindings, for building dual-chain wallets. Every wallet below is built on it.
sequentia-contracts Simplicity contracts: the pinned compiler, lints, templates and test harness.
smplx Simplex, the Simplicity development framework, with Sequentia support.
libwally-core Fork of libwally with the Sequentia transaction patches used by SeqLN.

Indexing and data

Repository What it is
sequentia-electrs The indexer and Esplora REST API for Sequentia and for Bitcoin testnet4.
sequentia-explorer The block explorer frontend.
sequentia-registry The asset registry: verified names for asset ids, plus contract templates, oracle keys and Arca operators.
sequentia-oracle Signed price attestations for contracts.
sequentia-pool-board The public board of staking pools.

The explorer’s API is public:

Use https://sequentiatestnet.com/testnet4/api/ for the Bitcoin testnet4 side.

Wallets

Repository What it is
sequentia-web-wallet The browser wallet: a single static page around SWK’s WebAssembly bindings.
ambra The mobile wallet: a Flutter interface over a shared Rust core.
sequentia-extension Ambra for Chromium, and the window.sequentia provider that websites connect through.
sequentia-connect Connects your own node, Lightning node and ark wallet to websites you allow, with every signature approved in your terminal.
fulmen Desktop Lightning wallet with a bundled SeqLN node.
arca-client Desktop app to join, or run, an ark.
seqognito Desktop mixing wallet over Tor.

Second layers

Repository What it is
seqln Core Lightning fork: Bitcoin and Sequentia from the same binary, with asset channels. See Lightning: SeqLN.
arca Ark for Sequentia, a covenant-tree fork of Bark. See Ark: Arca.
seqcj CoinJoin coordinator over confidential transactions.

Trading and finance

Repository What it is
seqdex The exchange engines: order-book relay, covenant orders, cross-chain swaps. See Swaps and SeqDEX.
seqdex-web The SeqDEX website.
pignus Collateralised lending in a covenant.
levo Launchpad.

Issuance and compliance

Repository What it is
openamp Issuer-governed restricted assets with a co-signing policy server.
opendamp Regulated assets enforced by covenants, and the tool that drives them.
SeqPal Tokenisation as a service, proof of concept.
sequentia-faucet The testnet faucet.

Bridges

Repository What it is
compages Operator-run bridge from Ethereum, Solana and Bitcoin. Proof of concept.
compages-reserves Public mirror of the bridge’s signed proof-of-reserves snapshots.
sbtc-bridge Application-level bridge that wraps BTC as SBTC. Not the consensus peg, and never required to use bitcoin with Sequentia.

Community and documentation

Repository What it is
emissio The community rewards platform.
sequentia-docs The tester guide served at sequentiatestnet.com/docs.

A note on older repositories

The organisation also holds repositories from earlier stages of the project (2023 and before), some with similar names. The ones listed on this page are the current ones.

Contributing

Issues and pull requests are welcome on every repository. Security problems should be reported privately: see Community.
